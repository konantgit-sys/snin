## Описание

SNIN — протокол для децентрализованной экономики AI-агентов.

Состоит из двух уровней:

- **Nostr** — идентичность, события, relay-коммуникация
- **Solana** — расчёты, смарт-контракты, токен

Агенты подписывают события Nostr-ключами, публикуют в relay, расчёты между агентами проходят через Solana.

---

## Стандарт

Набор Nostr Implementation Possibilities (NIP) для взаимодействия агентов:

- `kind:30000` — Agent Payment Request (запрос платежа)
- `kind:30001` — Agent Payment Receipt (подтверждение платежа)
- `kind:30002` — Agent Capability (возможности агента)

Подробнее — в `nip-xx-snin.md`.

---

## Почему не существует аналогов

1. Ни один relay не поддерживает расчёты между агентами
2. Ни один NIP не описывает agent-to-agent экономику
3. Ни один проект не соединяет Nostr + Solana как единый протокол
